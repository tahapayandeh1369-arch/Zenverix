## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tahapayandeh1369-arch/Zenverix.git
```

### 2. Open the project

```bash
cd Zenverix
```

### 3. Run locally

Open `index.html` in your browser.

For development, **VS Code + Live Server** is recommended.
